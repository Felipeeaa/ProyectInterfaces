# Sistema de Gestión de Acceso y Seguridad (Java) 🔐

Este proyecto es una aplicación de escritorio desarrollada en **Java** enfocada en la gestión segura de usuarios. Implementa un flujo completo de autenticación, desde el registro inicial hasta la recuperación y cambio de credenciales, priorizando la experiencia de usuario (UX) y la seguridad de los datos.

## 🚀 Funcionalidades Principales

* **Registro de Usuarios (Sign Up):** Creación de cuentas con validación de datos en tiempo real.
* **Autenticación Segura (Sign In):** Control de acceso protegido para usuarios registrados.
* **Gestión de Credenciales:** Módulo dedicado para el cambio de contraseñas de forma segura.
* **Interfaz Profesional:** Diseño de interfaces limpias y funcionales utilizando Java (JavaFX).

## 🛠️ Stack Tecnológico

* **Lenguaje:** Java ☕
* **Interfaz Gráfica:** JavaFX 
* **Seguridad:** Lógica de encriptación y validación de contraseñas.
* **Persistencia:** Gestión de datos de usuario.

## 📁 Estructura del Proyecto

El código está organizado siguiendo principios de diseño modular para facilitar el mantenimiento y la escalabilidad del sistema:
* `/src`: Lógica de negocio y controladores.
* `/view`: Archivos de interfaz y diseño visual.
* `/model`: Gestión de datos y objetos de usuario.
